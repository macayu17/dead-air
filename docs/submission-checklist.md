## Required

- [x] New project started during the entry period: October 31, 2026.
- [x] Ghost in the Machine theme: fictional ghost radio transmissions.
- [x] Open-weight AI is central: SmolLM2 generates the transmissions locally.
- [x] DEV draft follows the required sections and includes `devchallenge` and `hf26challenge`.
- [x] Draft explains the model, runtime, architecture, and reasons for using open technology.
- [x] Real local inference and an independent network-blocked generation were verified.
- [x] Desktop/mobile screenshots and a 54-second real browser walkthrough are prepared.
- [x] README, MIT license, model attribution, setup instructions, and verification notes are present.
- [x] Publish a public code repository and insert its real URL in the Code section: https://github.com/macayu17/dead-air.
- [x] Host the real demo video and insert its public URL in the Demo section: https://macayu17.github.io/dead-air/.
- [ ] Preview the DEV post and check both links without logging in.
- [ ] Publish the post before October 31, 2026 at 11:59 p.m. PDT (**November 1, 2026 at 12:29 p.m. IST**).

The entry is not submitted until the DEV post is published. Submit only one entry for this challenge. If another entry was already submitted, the official rules say only the first is considered. Repositories also need to be created within the challenge window. Note any later commits in the README.

## Personal eligibility

The entrant must be at least 18 (or the applicable age of majority), have an active DEV account and email, and satisfy the residency and other eligibility conditions in the general rules. The account holder should review and accept those rules before publication. If this is a team entry, credit every teammate's DEV handle; teams may have up to four people.

## Optional

Agent-session links and partner categories are optional. This project does not currently claim a partner category. Do not add one unless the corresponding technology is meaningfully used and demonstrated. A screenshot supports the post, but does not replace its required demo link or video walkthrough.

## Publication handoff

The draft now contains verified public repository and demo URLs. Set `published: true` only when publishing. Preview the post, verify the two required challenge tags, and record the resulting article URL after the site confirms publication.

`docs/index.html` and `docs/demo.mp4` are hosted by GitHub Pages from `/docs` on the `main` branch. Public video playback was verified without logging in. This hosts the recorded walkthrough; the interactive inference server runs locally. Judges can watch the project work without installing a model.
