# Demo walkthrough

Record the running app rather than slides or a mockup. Use the default railway station note and the unsettling mood. Keep the browser recording uninterrupted during the actual request.

1. Show the title and receiver. Explain: "Dead Air is a fictional radio station. A small open-weight model makes the transmissions locally."
2. Show the place, strange detail, and mood controls. The starting note hears its own voice on the station announcements.
3. Click Tune in. Show the real loading or generation state. If the model was downloaded before recording, say that it was cached; do not imply the first download is instant.
4. Read the received transmission. Point out any awkwardness rather than editing it out of the recording.
5. Save the transmission. Show that the export includes the place, listener note, model, and received time.
6. Scroll to Behind the Static. Explain the one-time Hugging Face download, local inference, and the small model's limits.

The recorded walkthrough can be silent: the controls and generated text should be readable. Upload the video to a publicly accessible host, then place that link in the DEV post's Demo section. A video on this computer is not a public demo link.
